# 塔防游戏波次详情

本文档基于 `GameConfig.ts` 和 `GameEngine.ts` 的配置，详细描述每一波的敌人组成、数量、击杀奖励以及进入每一波前的累计金币。

## 基本信息
- **初始金币**: 40
- **每只敌人击杀奖励**: 2 金币（所有敌人击杀收益相同）
- **前10波**: 使用预定义配置
- **第10波之后**: 敌人数量固定为第10波的配置（basic: 0, fast: 6, tank: 9，总计15只）

## 说明
- **累计金币计算**: 初始40 + 之前所有波次的敌人总数 × 2
- **第10波之后**: 敌人数量、奖励和累计金币增长固定不变
- **敌人类型**:
  - BASIC: 生命值40, 速度50, 奖励2
  - FAST: 生命值30, 速度70, 奖励2
  - TANK: 生命值150, 速度40, 奖励2
- **倍率增长**: 第10波之后，敌人生命值和速度会根据 `healthGrowthFactor` (1.2) 和 `speedGrowthFactor` (1.1) 倍率增长，但数量不变

## 每一波敌人的生命值、速度和总生命值
- **前10波**: 敌人使用基础生命值和速度，无倍率增长。
- **第10波之后**: 生命值倍率 = 1.2^(波次-10)，速度倍率 = 1.1^(波次-10)，速度上限250。
- **总生命值**: 每波所有敌人的生命值总和（考虑倍率）。
